# Changelog

All notable changes to PaperLite are recorded here.

## 0.1.0 - 2026-09-11

- Added continuous vertical PDF scrolling with lazy page rendering.
- Added current-page tracking and page jump controls.
- Added document-wide text search with highlighted matches.
- Added pen, highlighter, text, eraser, undo, and redo tools.
- Added adjustable zoom and annotation settings.
- Added native open, drag-and-drop, and annotated-copy export workflows.
- Added a lightweight offline Windows build and portable executable.
