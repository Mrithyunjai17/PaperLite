# Security policy

## Supported version

Security fixes are applied to the latest PaperLite release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature from the repository's **Security** tab. Do not include confidential PDFs, passwords, personal information, or other sensitive data in a public issue.

Include the affected version, a concise reproduction, the expected impact, and any suggested mitigation. Reports will be acknowledged as soon as practical.

## Data handling

PaperLite processes PDFs locally. It does not include telemetry, analytics, advertising, user accounts, or application-level network requests.
